# 服务监控与公开状态页

在监控项目中添加探测目标后，系统按设定间隔自动检测并在仪表盘汇总；开启「公开页面」即可把结果发布为免登录状态页。（v1.16 新增）

## 探测方式

| 方式 | 说明 |
| --- | --- | --- |
| HTTP | 支持 GET / POST |
| TCP | 端口连通性检测 |
| ICMP | Ping 检测 |

- 每个监控可挂载多个探测目标，支持二次编辑与外链跳转开关。
- 修改目标的**地址**、**类型**或**方法**会清空该目标的历史数据并重新统计。
- 仪表盘展示近 24 小时的延迟柱状图。

## 公开状态页

### 访问地址

- **自定义短路径**：「公开页设置」中填写 1–32 位小写字母、数字、`-` 或 `_`，保存后通过 `/status/你的名字` 访问。
- **系统令牌**：留空短路径时使用系统令牌访问。

两种链接长期并存，访客无需登录即可查看检测结果。

### 页面自定义

| 项目 | 说明 |
| --- | --- |
| 标题 | 自定义状态页标题 |
| 公告条 | 展示维护公告等内容 |
| 品牌图标 | PNG / JPG / GIF / WebP 上传（不超过 4MB），或填写外链 |
| 主题 | 科技蓝 / 暖米金两种配色 |

访客的明暗模式切换仅作用于状态页自身，不影响管理面板配色。

### 外链跳转

勾选「跳转」的目标在公开页上可直接点击访问。
