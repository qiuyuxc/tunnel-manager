# 服务监控与公开状态页

在监控项目中添加探测目标后，系统按设定间隔自动检测并在仪表盘汇总；开启「公开页面」即可把结果发布为免登录状态页。（v1.16 新增）

## 探测方式

| 方式 | 说明 |
| --- | --- | --- |
| HTTP | 支持 GET / POST |
| TCP | 端口连通性检测 |
| ICMP | Ping 检测 |

- 每个监控可挂载多个探测目标，支持二次编辑与外链跳转开关。
- 修改目标的**地址**、**类型**或**方法**会清空该目标的历史数据并重新统计。
- 仪表盘展示近 24 小时的延迟柱状图。

## 公开状态页

### 访问地址

- **自定义短路径**：「公开页设置」中填写 1-32 位小写字母、数字、`-` 或 `_`，保存后通过 `/status/你的名字` 访问。
- **系统令牌**：留空短路径时使用系统令牌访问。

两种链接长期并存，访客无需登录即可查看检测结果。

### 自定义域名

在「公开页设置」中填写访问域名，如 `status.example.com`。保存后访问域名的根路径会跳转到当前监控的公开页，地址栏保留该域名。

一个访问域名只能绑定一个监控。通过该域名只能打开当前状态页、公开数据接口和页面所需的静态资源；管理后台、登录接口、其他 API 和其他状态页都会返回 404。关闭公开页后，该域名也会返回 404。

访问域名全局唯一，不能与面板域名相同。面板域名由管理员在「全局设置」中维护。

#### 自动配置前提

自动配置使用监控所有者当前启用的 Cloudflare 连接和已选择的 Tunnel，需要满足以下条件：

1. 管理员已经填写面板域名。
2. 当前用户已经连接 Cloudflare，并选择面板所在的 Tunnel。
3. Tunnel ingress 中存在一条精确匹配面板域名、未设置 `path` 的规则。
4. 访问域名及优选模式的辅助回源域名，都属于当前 Cloudflare 连接可管理的 Zone。

面板会复制面板域名 ingress 的服务地址和源站参数，但会移除 `httpHostHeader`。状态页依靠访客原始 `Host` 识别监控，固定回源 Host 会让请求无法匹配对应状态页。

#### 直连与优选

| Cloudflare 资源 | 直连 | 优选 |
| --- | --- | --- |
| 访问域名 DNS | 橙云 `CNAME`，指向 `<tunnel-id>.cfargotunnel.com` | 灰云 `CNAME`，指向本次选择的优选 CNAME |
| 辅助回源域名 DNS | 不需要 | 橙云 `CNAME`，指向 `<tunnel-id>.cfargotunnel.com` |
| Custom Hostname | 不创建，保存时清理同名记录 | 主机名为访问域名，Custom Origin 为辅助回源域名 |
| Tunnel ingress | 添加访问域名 | 同时添加访问域名和辅助回源域名 |

保存时会创建或更新同名 DNS、Custom Hostname 和 ingress 规则。不要把这些主机名同时用于其他服务，否则现有配置会被覆盖。

**直连模式**适合不需要优选线路的状态页。访问域名开启 Cloudflare 代理后直接进入 Tunnel，不需要辅助回源域名。

**优选模式**把访问链路和回源链路分开：

```text
访问域名 --灰云 CNAME--> 优选 CNAME
访问域名 --Custom Hostname--> Custom Origin（辅助回源域名）
辅助回源域名 --橙云 CNAME--> <tunnel-id>.cfargotunnel.com
```

访问域名用于访客接入，辅助回源域名负责把 Cloudflare SaaS 回源请求送进 Tunnel，两者不能相同。辅助回源域名建议使用单独、未承载其他服务的主机名，也不要填写面板域名。

「本次优选 CNAME」可以从预设中选择，也可以手动输入。留空时使用全局设置中的默认优选 CNAME；两处都未配置时，状态页设置仍会保存，但自动配置会返回警告。

#### 自动配置失败

Cloudflare 配置失败不会撤销已经保存的状态页设置。接口响应会包含 `domain_warning`，页面也会显示具体原因和三组可复制的检查信息：DNS CNAME、SaaS Custom Hostname、cloudflared ingress。

常见原因包括：

- 全局设置没有填写面板域名。
- 当前用户没有启用 Cloudflare 连接或没有选择 Tunnel。
- Tunnel 中找不到面板域名对应的 ingress 规则。
- 访问域名或辅助回源域名不在当前连接可管理的 Zone 中。
- 本次与全局优选 CNAME 都为空。

修正配置后再次保存公开页设置，面板会重新执行自动配置。

::: warning 手动配置时保留原始 Host
cloudflared 按 `Host` 匹配 ingress。手动添加状态页规则时，服务地址与面板域名规则保持一致，但不要设置 `httpHostHeader`。新规则应放在末尾兜底规则之前，否则请求会落到默认的 `http_status:404`。

面板若通过 A 记录或 nginx 暴露，自动配置不适用，需要自行配置 DNS、HTTPS 和反向代理，并确保转发时保留原始 Host。
:::

::: tip HTTP 跳转与证书
HTTP 是否跳转到 HTTPS 由 Cloudflare 的 Zone 和 Custom Hostname 设置决定。看到 Cloudflare 返回 `301 Moved Permanently` 并跳到 HTTPS，通常是边缘侧开启了 HTTPS 重定向。优选模式首次创建 Custom Hostname 后，需要等待证书和主机名状态生效。
:::

::: warning 清理外部资源
清空自定义域名或删除监控不会自动删除 Cloudflare DNS、Custom Hostname 和 Tunnel ingress。停用域名后请到 Cloudflare 中清理对应资源，避免旧主机名继续指向面板服务。
:::

### 页面自定义

| 项目 | 说明 |
| --- | --- |
| 标题 | 自定义状态页标题 |
| 公告条 | 展示维护公告等内容 |
| 品牌图标 | PNG / JPG / GIF / WebP 上传（不超过 4MB），或填写外链 |
| 主题 | 科技蓝 / 暖米金两种配色 |

访客的明暗模式切换仅作用于状态页自身，不影响管理面板配色。

### 外链跳转

勾选「跳转」的目标在公开页上可直接点击访问。
