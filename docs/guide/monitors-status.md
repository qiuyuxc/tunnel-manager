# 服务监控与公开状态页

在监控项目中添加探测目标后，系统按设定间隔自动检测并在仪表盘汇总；开启「公开页面」即可把结果发布为免登录状态页。（v1.16 新增）

## 探测方式

| 方式 | 说明 |
| --- | --- | --- |
| HTTP | 支持 GET / POST |
| TCP | 端口连通性检测 |
| ICMP | Ping 检测 |

- 每个监控可挂载多个探测目标，支持二次编辑与外链跳转开关。
- 修改目标的**地址**、**类型**或**方法**会清空该目标的历史数据并重新统计。
- 仪表盘展示近 24 小时的延迟柱状图。

## 公开状态页

### 访问地址

- **自定义短路径**：「公开页设置」中填写 1–32 位小写字母、数字、`-` 或 `_`，保存后通过 `/status/你的名字` 访问。
- **系统令牌**：留空短路径时使用系统令牌访问。

两种链接长期并存，访客无需登录即可查看检测结果。

### 自定义域名

在「公开页设置」里填写一个完整主机名（如 `status.example.com`），保存后访客直接访问 `https://status.example.com` 即可打开该状态页——面板按请求的 `Host` 头识别并跳转到对应的公开页，地址栏保留你的域名。

原有的 `/status/{短路径}` 链接不受影响，同一个自定义域名下也仍可访问其他公开页，因此多个状态页可以共用一个域名。

保存自定义域名时，面板会尝试自动完成以下配置：

1. 使用该监控所有者当前启用的 Cloudflare 连接与已选择的隧道。
2. 确认自定义域名所在的 zone 可由该连接管理。
3. 在隧道配置中查找精确匹配面板域名、且未设置 path 的 ingress 规则，复制它的服务地址和源站参数，为自定义域名新增规则。
4. 创建或更新指向 `<隧道 ID>.cfargotunnel.com` 的橙云 `CNAME` 记录。

因此，自定义域名的 zone 与面板隧道必须能通过同一个 Cloudflare 连接访问，且隧道配置中必须已有可供复制的面板域名 ingress 规则。自动配置失败不会撤销已经保存的域名，界面会显示警告；此时可按下方提示手动检查 DNS 与 ingress。

手动配置分两步：

1. **DNS**：在该域名所在的 DNS 服务商添加 `CNAME` 记录，目标为 `<面板所在隧道的 ID>.cfargotunnel.com`，开启 Cloudflare 代理（橙云）。
2. **隧道**：面板通过 cloudflared 暴露时，给隧道加一条 ingress 规则，主机名为该域名，服务和源站参数与面板域名的规则保持一致。

::: warning 隧道匹配不到主机名会返回 404
cloudflared 按 `Host` 匹配 ingress 规则，匹配不到就落到规则表末尾的兜底规则（默认 `http_status:404`），请求根本到不了面板。若不想每加一个域名都改隧道，可以改用通配主机名（如 `*.example.com`）指向面板，或把末尾兜底规则指向面板。

面板若是 A 记录直连或前面挂了 nginx 反代，则自动配置不适用，只需手动配置 DNS 和反向代理，隧道不参与。
:::

自定义域名全局唯一，且不能填写面板自身的域名（否则会占用面板根路径）。面板域名在管理员首次登录时自动记录，管理员可在全局设置中修改。

### 页面自定义

| 项目 | 说明 |
| --- | --- |
| 标题 | 自定义状态页标题 |
| 公告条 | 展示维护公告等内容 |
| 品牌图标 | PNG / JPG / GIF / WebP 上传（不超过 4MB），或填写外链 |
| 主题 | 科技蓝 / 暖米金两种配色 |

访客的明暗模式切换仅作用于状态页自身，不影响管理面板配色。

### 外链跳转

勾选「跳转」的目标在公开页上可直接点击访问。
