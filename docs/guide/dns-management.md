# DNS 记录管理

Web 和 Android 的「DNS 管理」页面提供独立于域名绑定的记录维护能力。所有操作沿用当前登录用户的 Cloudflare 账户、`dns` 权限及逐条审计，不借用其他用户凭据。

## 选择区域

页面顶部按 Zone 切换。区域选择器支持按域名模糊定位，无需复制 Zone ID。

## 支持的记录类型

| 类型 | 说明 |
| --- | --- |
| A / AAAA | IPv4 / IPv6 地址指向 |
| CNAME | 别名指向，常用于优选与 CDN 场景 |
| TXT | 文本记录，验证、SPF 等 |
| MX | 邮件交换记录，可设置优先级 |
| NS | 子域委派的名称服务器域名，不修改注册商处的权威名称服务器 |
| SRV | 完整 `_服务._协议.域名`、优先级、权重、端口和目标域名 |
| CAA | `flags`、`tag`（如 `issue` / `issuewild` / `iodef`）和 `value` |
| PTR | 反向解析目标域名；需要有权管理相应反向 Zone |

仅支持以上九类新增和编辑，不代表支持所有 Cloudflare 类型。未知类型继续展示为只读，不能编辑、勾选或删除。SRV/CAA 的 `data` 缺失、无效或包含未支持字段时，双端也会保持只读，避免覆盖丢失字段。

## 编辑能力

- TTL：`1` 为自动，或 `60–86400` 秒；省略时默认 `1`，显式 `0` / `null` 无效。
- 代理状态：只有 A / AAAA / CNAME 可开启，其他类型强制仅 DNS。省略 `proxied` 默认 `false`，`null` 无效。
- MX 优先级：`0–65535` 整数，编辑保留 `0`；空 MX 可填目标 `.`，优先级必须为 `0`。
- SRV：优先级、权重、端口均为 `0–65535` 整数。目标可为域名或 `.`；用结构化 `data` 往返保存，不从展示文本猜测字段。
- CAA：flags 为 `0–255` 整数，tag 为 1–15 个字母或数字，value 为不超过 4096 字节的单行文本，可为空。
- TXT：保留文本首尾空格；单条允许多行。目标域名使用 ASCII/Punycode。

## 批量新增

无需勾选已有记录，点击页面顶部的 **批量新增**：

1. 选择一个 Zone，填写共用的类型、名称、TTL 和适用的代理/MX 优先级。
2. 粘贴解析值，每行一条。仅支持 **A / AAAA / TXT / MX / NS / PTR**，CNAME 同名多目标有冲突，SRV/CAA 需结构化字段，因此这三类仅单条新增。
3. 核对带原始行号的预览。每批最多 **100 条非空行（含重复行）**；空行忽略，同批重复和已加载的同名同类型相同值跳过。IPv6 按地址去重，域名忽略大小写和末尾点，TXT 区分大小写并保留空格，不按逗号拆分。任意行无效时整个批次不发送。
4. 确认后逐条串行调用现有单条创建 API，显示各行结果。共享字段在首次提交后锁定，避免重试时误改目标。
5. 明确成功的行从输入移除，明确失败的行保留供手动重试，绝不自动重发成功行。此操作不是原子事务，不回滚已成功记录。

批次绑定打开窗口时的登录会话和目标区域。切换登录会话后，不再发送剩余记录；Web 页面卸载、Android 窗口关闭或宿主销毁时也会停队列。未调用的行标为 **未发送**，而不是结果未知。已经发出的请求仍可能完成，不会回滚；请核对已创建记录后，在当前账户下重新打开批量新增。旧批次不会借用新账户的令牌继续提交。

::: warning 结果未知不等于未创建
超时、断连、网关错误或后端无法读取服务商响应时，请求可能已经写入。界面标为 **结果未知，请核对后再重试**，立即停止后续队列，尚未调用的行标为 **未发送**。输入仅保留失败、未知和未发送项；必须先在 Cloudflare 或刷新记录核实、移除实际已创建的行，再明确确认已核对，才能重试。关闭弹窗会清空本批输入与结果，不会撤销已创建记录。
:::

本地去重不保证服务商没有并发新增的重复记录；最终冲突、NS 委派数量和账户限制仍以 Cloudflare 返回为准。跨行 TXT 请使用单条编辑器。

## 批量修改与删除

列表仍可多选后批量修改或批量删除。SRV/CAA 的结构化字段和类型必须逐条编辑，批量修改仅保留其原始 `data` 并允许改 TTL；MX 记录改 TTL 时保留原优先级。

::: warning
批量删除不可恢复，涉及生产域名时建议先核对筛选条件再勾选。
:::

字段结构参考 [Cloudflare DNS 类型文档](https://developers.cloudflare.com/dns/manage-dns-records/reference/dns-record-types/)与[当前官方 TypeScript SDK](https://github.com/cloudflare/cloudflare-typescript/blob/main/src/resources/dns/records.ts)。
