# DNS 记录管理

「DNS 管理」页面提供独立于域名绑定的记录维护能力，适合直接增删改查各类解析。（v1.13 / v1.14 迭代增强）

## 选择区域

页面顶部按 Zone 切换。区域选择器支持按域名模糊定位，无需复制 Zone ID。

## 支持的记录类型

| 类型 | 说明 |
| --- | --- |
| A / AAAA | IPv4 / IPv6 地址指向 |
| CNAME | 别名指向，常用于优选与 CDN 场景 |
| TXT | 文本记录，验证、SPF 等 |
| MX | 邮件交换记录，可设置优先级 |

## 编辑能力

- TTL：可指定秒数或使用自动值
- 代理状态：开关 Cloudflare 小云朵代理（TXT/MX 默认关闭）
- MX 优先级：仅在 MX 类型时出现

## 批量操作

列表支持多选后**批量修改**（v1.13）与**批量删除**（v1.14），批量动作前会汇总变更预览，确认后才提交到 Cloudflare。

::: warning
批量删除不可恢复，涉及生产域名时建议先核对筛选条件再勾选。
:::
