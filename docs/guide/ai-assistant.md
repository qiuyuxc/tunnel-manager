# AI 助手

AI 助手将自然语言需求拆成待确认任务。桌面端从侧边栏进入；网页移动端和 Android 原生 App 保留底部加号，在快捷菜单中选择 **AI 助手**。正式页面为 `/assistant`，不使用设计稿的模拟身份或示例执行逻辑。

## 配置连接

打开助手右上角的连接配置，填写 API 端点、模型名称和 API 密钥。端点支持兼容 Chat Completions 的服务，例如 `https://api.example.com/v1`，也可填写完整的 `/chat/completions` 地址。模型需要支持工具调用，否则只能进行文字对话。模型名称按服务商提供的 ID 填写，不预设默认付费模型。

- 默认是个人模式，每个用户单独保存配置，管理员也有自己的个人配置。
- 管理员可切换到「全站共享配置」，填写专用连接并开启共享。此后所有用户使用该连接，普通用户只能查看是否可用，不能读取共享端点、密钥或修改开关。
- 关闭共享后恢复个人配置。共享不可用时直接报错，不自动改用个人密钥。
- 保存后不返回密钥。留空保留旧密钥，填写新值替换；更换端点必须重新填写密钥，避免将旧密钥发送给其他服务。
- 密钥使用应用加密密钥加密后存储。个人密钥的加密上下文绑定用户 ID，共享密钥使用独立上下文。备份和恢复时须保留 `APP_ENCRYPTION_KEY` 或数据库内自动生成的加密密钥。

端点支持 HTTP 和 HTTPS、本机 / 内网地址、IPv4 / IPv6，以及 1–65535 范围内的自定义端口。例如本机代理 `http://127.0.0.1:8787/v1`、Ollama 的兼容接口 `http://localhost:11434/v1`，或内网服务 `https://192.168.1.10:8443/v1`。模型和服务仍需兼容 Chat Completions 与工具调用，并填写服务接受的密钥。

连接由后端发起：`localhost`、`127.0.0.1` 和 `::1` 指运行 Tunnel Manager 后端的电脑或容器，不是浏览器或 Android App 所在设备。容器访问宿主机服务时，应使用部署环境提供的宿主机地址（例如已配置的 `host.docker.internal`）或可达的内网地址。

HTTP 会明文传输 API 密钥与对话，仅适合本机或可信网络；跨公网建议使用 HTTPS。HTTPS 仍校验证书，自签名证书需由后端系统信任。不接受 URL 用户密码、查询参数、片段、未指定地址、链路本地地址（包括 `169.254.169.254`）、组播及保留地址，并拦截 `fd00:ec2::254` 元数据地址。连接时再次校验全部 DNS 结果、直接连接已校验的 IP，不跟随重定向，也不使用系统代理。

允许本机和内网端点意味着已登录用户可以让后端向这些网络发送 AI 请求；这不是内网访问隔离机制。多人部署时只向可信用户开放个人连接配置，或由管理员开启全站共享固定端点，并用后端防火墙限制不应访问的目标。

## 对话与资源

输入内容及该会话的近期消息会发送给配置的服务商。不要在消息中粘贴密钥、连接器令牌或密码。

「允许发送我的资源名称与 ID」默认不选。开启后，可将当前用户权限内的隧道、区域及本人监控项目摘要发送给 AI；不发送 Cloudflare 凭据、通知配置或其他用户的会话。列表最多各取 100 项，未读到的资源 ID 可由用户明确提供。

会话和任务保存在服务端、按用户隔离，共享连接不共享历史。每个用户最多保存 20 个会话；每会话最多 48 条消息和 48 个任务，每次最多生成 8 个任务。达到限制后删除旧会话或新建会话。切换页面会保留当前草稿；未发送草稿只在客户端内存中，刷新网页或退出 App 后不保证保留。

## 支持的任务

| 任务 | 确认后的效果 | 权限 |
| --- | --- | --- |
| 创建隧道 | 创建 Cloudflare Tunnel，不部署主机或启动连接器；令牌请到隧道页面获取 | `tunnels` |
| 新增直连域名绑定 | 为已有隧道新增源站路由及代理 CNAME，TTL 自动，将服务公开到互联网 | `domain_bind` |
| 新增 DNS 记录 | 新建 A / AAAA / CNAME / TXT / MX 记录 | `dns` |
| 创建监控项目 | 创建私有空项目，不自动公开或开启告警 | `monitors` |
| 添加 HTTP 探测目标 | 向已有项目添加 GET 探测，随后开始周期访问目标 | `monitors` |

工具遵守原有角色、用户组和 Cloudflare 授权边界。模型只能提交固定工具及其参数，不能执行 shell、指定任意业务 API、操作用户权限或读取密钥。任务执行时重新检查权限和 Cloudflare 连接，连接切换后需要重新生成计划。

本版不支持修改或删除已有记录、优选 / SaaS 域名绑定、自动安装连接器、依赖前一步结果的同批任务、流式输出或自动回滚。创建监控项目或隧道后，先确认执行，再用真实资源 ID 继续下一步。已有路由或 DNS 会阻止新增直连绑定；高级变更请到相应业务页面操作。

## 确认、暂停与重试

Web 宽屏在右侧显示任务清单；手机和平板窄屏，以及 Android 原生 App，直接在对话中显示可勾选卡片，新任务到达或重新打开会话时会定位到待确认项。顶部「待确认」按钮可再次定位，不需要在对话中输入“确认”。已完成或已取消的任务保留状态，不再显示勾选框。原生端刷新会保留仍待确认的勾选项，切换会话则清空勾选；二次确认只执行当时选定的任务。

手机网页和原生助手的输入框默认一行，长消息在达到高度上限后内部滚动，发送按钮与输入框同排。原生输入保留换行，最多显示四行、最多 8000 字符。隐私说明按需打开，资源授权仍默认不勾选。助手页使用紧凑底栏，原生端键盘弹出时隐藏底栏并释放预留空间，收起键盘或离开助手后恢复对应布局。

1. 查看任务清单，核对资源 ID、域名、源站、DNS 值、代理和探测间隔等具体参数。
2. 勾选要执行的任务，再进行一次执行确认。未选任务不执行，纯对话不产生写操作。
3. Web 最多同时发送两个独立任务，Android 按所选顺序逐项执行。服务端记录各项真实状态，不把动画当执行结果。
4. 暂停仅针对待执行任务。恢复后回到待确认状态；取消不会撤销已经完成的资源操作。
5. 超时、服务重启或执行错误时，结果可能是「需核对」。先检查真实资源，再确认没有重复创建后重试。完成的任务不能再次执行；并发重复请求也会被拒绝。

直连绑定涉及 DNS 和隧道配置两次写入，不是原子事务。助手保留完整隧道配置和未修改字段，在写路由前再次比较配置；检测到变化则停止，不自动覆盖或回滚。Cloudflare 外部控制台没有与本服务共用锁，操作期间避免同时编辑同一隧道。失败时可能已创建 DNS，必须同时检查 DNS 与路由，不能盲目重试。

执行记录写入原业务审计分类。审计不记录 API 密钥或完整对话。AI 服务的费用、限额和数据保留规则由所配置服务商决定，开启共享前应在服务商侧设置预算和额度。

## 开发验证

- 后端：在 `backend` 运行 `go test ./...`。
- Web：在 `frontend` 运行 `npm test`、`npm run build`。
- 原生：在 `android` 运行 `gradle --offline --max-workers=2 :app:assembleDebug`；按本机配置设置 `JAVA_HOME`。
- 浏览器：启动前端开发服务器（默认测试地址 `127.0.0.1:8084`）及启用 CDP 的 Chromium（默认 `9223`），运行 `node frontend/tests/assistant-browser.mjs`。可通过 `ASSISTANT_TEST_ORIGIN`、`ASSISTANT_TEST_CDP`、`ASSISTANT_TEST_OUTPUT` 覆盖地址和截图目录。

浏览器测试拦截业务 API，禁止外部请求，覆盖窄屏、明暗主题、勾选确认、暂停恢复、共享只读和密钥不写本地存储，不调用付费模型或真实 Cloudflare 写接口。APK 构建通过不等于真机 UI 或真实服务联调已验证。
