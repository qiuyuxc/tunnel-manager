# 站点品牌与全局设置

「全局设置」页管理面板自身的外观与常用预设。

## 站点品牌

可自定义以下公开可见的信息：

- 站点名称与描述
- 导航图标与登录页图标
- 浏览器标题
- 站点图标（favicon），支持自定义上传

上传接口为 `POST /api/uploads`，图片会存储在数据目录下的 `uploads/` 中。

## 首页（落地页）

「启用首页（落地页）」开关控制站点的门面：

- **开启**：访问站点根路径会先看到一个公开的门户首页，展示站点名称与描述、功能一览和 GitHub 仓库链接；顶栏提供明暗模式切换，已登录用户可从首页进入控制台
- **关闭**（默认）：保持原有行为——未登录直接进入登录页

首页无需登录即可访问，适合对外展示。

## 常用 CNAME 组

维护一组常用的优选 CNAME 值，绑定时可直接下拉选择而无需重复输入。第一项之外的顺序即下拉框中的排列顺序。

## 全局默认优选 CNAME

优选模式下绑定域名的默认辅助指向。留空使用内置默认值，单次绑定时也可以临时覆盖。

## Cloudflare 连接状态

同一页面可查看当前凭据来源（OAuth 或静态 Token）、授权账户并可切换；详见 [Cloudflare OAuth 连接](/guide/cloudflare-oauth)。
