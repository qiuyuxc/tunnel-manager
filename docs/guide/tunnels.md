# 隧道管理与路由

隧道是 Cloudflare Tunnel 的核心对象：所有域名绑定最终都落到某个隧道的 Ingress 路由上。

## 创建隧道

在「隧道」页面点击新建并填写名称即可。创建成功后面板会展示 **cloudflared 连接令牌与运行命令**，直接复制到目标机器执行即可把隧道跑起来。

::: tip
连接命令包含敏感令牌，请勿截图或粘贴到公开场合。
:::

## 选择当前隧道

面板的绑定与配置操作都围绕「当前选定的隧道」进行。多隧道时先在列表中选定，再回到绑定页面操作。

## 管理应用程序路由（Ingress）

进入隧道详情可以查看、编辑和删除 Ingress 路由：

- 每条路由由**请求匹配规则 + 转发地址**组成
- 新增路由后立即生效于 Cloudflare 配置
- 删除路由时可选择**连带删除对应的 DNS 记录**，避免留下悬空 CNAME（v1.14 新增联动）

路径型规则会被原样保留，例如 `/api -> localhost:9000` 这类仅路径转发的条目。

## 删除隧道

删除操作会从 Cloudflare 移除整个 Tunnel 对象，其下所有 Ingress 一并消失；DNS 记录不会被自动清理，如需彻底下线请在 DNS 管理页手动处理对应 CNAME。
