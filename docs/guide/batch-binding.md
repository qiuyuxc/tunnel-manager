# 批量域名绑定

单个绑定页一次处理一组域名；「批量绑定」页一次提交多个绑定组，每组可独立选择绑定模式、转发地址与优选 CNAME。（v1.14 起）

## 使用流程

1. 点击「添加分组」，得到一行为空白的绑定组
2. 每组分别选择：
   - **绑定模式**：简化直连 / 优选模式，各互不影响
   - **主域名**（及优选模式下的辅助域名）
   - **转发地址**：本组流量的实际去处
   - **优选 CNAME**（仅优选模式）：留空使用全局默认值
3. 提交后系统逐组执行并回报结果

## 结果反馈

批量接口逐组返回成败：某一组失败不会中断其余组的执行，结果列表会标明每组的具体错误（如域名已被占用、Zone 不存在等）。

## 与单组绑定的关系

两种模式的行为与[单组绑定](/guide/domain-binding)完全一致：简化直连只建 Tunnel 路由加代理 CNAME；优选模式额外创建 SaaS Custom Hostname。API 层面对应 `POST /api/domain/bind-batch`。
