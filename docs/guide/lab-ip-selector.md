# IP 优选实验室（实验性）

IP 优选实验室把“直连探测、延迟排序、DNS 更新”做成一个可配置的实验任务。它不绑定特定 CDN：只要填写业务域名、TLS SNI 与授权探测的 IP 段，就可以筛选出可用且延迟较低的地址。

## 开启入口

1. 以管理员身份进入 **管理后台 → 系统设置**。
2. 打开 **实验性功能**。
3. 保存后，侧边栏会出现 **IP 优选实验室**。

关闭开关后，前端入口隐藏，实验功能 API 也会返回 `404`。

## 探测配置

| 配置 | 说明 |
| --- | --- |
| Host | HTTP `Host` 请求头，通常填写托管在 Cloudflare 或其他平台的业务域名 |
| SNI | TLS Server Name；留空时自动使用 Host |
| 探测路径 | 建议使用轻量、可缓存的健康检查路径 |
| 接受状态码 | 逗号分隔，例如 `200,204` |
| 超时 | 每个连接 1–15 秒 |
| 并发数 | 1–256，请按服务器与网络承受能力设置 |
| 保留 Top N | 1–100，只保留延迟最低的 N 个 IP |

IP 段支持三种写法，可用逗号、空格或换行分隔：

```text
1.2.3.4
1.2.4.0/24
1.2.5.10-1.2.5.20
```

系统会展开并去重 IP，单次最多探测 65,536 个地址。

## 执行与进度

点击 **立即执行** 后，页面会显示：

- 当前阶段：准备、探测、更新 DNS、完成
- 扫描百分比
- 已扫描 / 总数
- 匹配数量

执行历史最多保留 20 条。每条记录包含扫描数、匹配数、Top IP、错误信息以及是否更新了 DNS。

## 分段统计与剔除

结果会按你输入的原始段聚合，例如 `1.2.4.0/24` 或 `1.2.5.10-1.2.5.20`。

**未命中 IP 段**卡片会单独列出所有 `0 命中` 的段，并汇总可减少的后续探测 IP 数。你可以：

- **复制未命中段**：复制到剪贴板，手动回填或比对
- **一键剔除并保存**：自动从当前配置中移除这些段并保存

如果当前配置在扫描后被手动修改过，一键剔除只移除仍与最近一轮记录完全一致的段，避免误删新内容。

## 自动更新华为云 DNS

开启 **自动更新华为云 DNS** 后，任务会把延迟最低的 Top N IP 写入指定 A 记录。

| 配置 | 说明 |
| --- | --- |
| Zone 名称 / Zone ID | 二选一；填写 Zone ID 可跳过查询 |
| A 记录 | 要创建或更新的记录名 |
| TTL | 60–86,400 秒 |
| API Endpoint | 默认 `https://dns.myhuaweicloud.com`，仅支持 HTTPS |
| Access Key / Secret Key | 华为云 API 凭证 |

Secret Key 会使用 `APP_ENCRYPTION_KEY` 进行 AES-GCM 加密存储，接口只返回“是否已设置”，不会回传明文。

## 定时执行

开启 **定时执行** 后，任务会按设定间隔自动执行，间隔范围为 5–1440 分钟。服务重启后会参考最近一次执行时间继续调度。

::: warning
请只探测你拥有或获得授权的服务与 IP 段。大规模探测应使用低并发、轻量路径，并注意源站、CDN 与运营商的网络策略。
:::
