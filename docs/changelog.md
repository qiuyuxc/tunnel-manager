# 版本历史

整理自仓库发布提交，更早的版本细节见 [GitHub Releases](https://github.com/qiuyuxc/tunnel-manager/releases)。

## v2.4.1

- 修复 App 登录状态失效后无限闪屏：会话过期时未清除本地凭据，登录页会立刻再次进入控制台、又拿到 401 弹回，循环往复；现在会清除会话、回到登录页并提示「登录状态已失效，请重新登录」
- App 中任何接口返回 `401` 都会交给控制台外壳统一处理，并保证只处理一次；`403` 仍按权限不足处理，不会误踢登录
- 会话有效期由 12 小时延长到 7 天
- 监控概览图表窗口由 12 小时改为近 7 天：每天一柱（当天峰值延迟 + 当天最差状态），没有数据的日子也占位，不再把某一天的流量压成一根超宽柱子
- 心跳历史保留期改为 8 天（每个目标上限 10080 条），以支撑 7 天窗口
- 概览接口新增 `bucket_sec` 与 `uptime`（`uptime_24h` 保留兼容）；客户端在字段缺失时按小时桶渲染，旧服务端配新客户端不会标错时间

## v2.4.0

- 新增 Android 原生 App：概览、监控、隧道绑定、DNS、IP 优选实验室、通知与关于页均为原生实现，底部标签导航 + 更多页，直连同一套后端 API，见[App 使用说明](/guide/android-app)
- App 通知接入系统通知渠道：后台低频轮询 `/api/alerts`，不打开网页也能在手机上收到监控状态变化
- App 登录页内嵌 Cloudflare Turnstile：开启人机验证时全程在原生页面完成，不再跳转网页，也不受浏览器残留登录态影响
- App 登录页与控制台跟随主题偏好切换亮色 / 暗色（Vercel 亮 / Vercel 暗），启动闪屏按主题选择日间 / 夜间插画
- 前端新增窄屏底部标签导航与半屏弹窗，监控、DNS、IP 优选实验室等页面在手机上不再横向挤压
- 双主题落地页：Vercel 风格（企业蓝，亮 / 暗）与 Claude 风格（暖色，亮 / 暗）
- 安全加固：错误信息统一脱敏，Telegram Bot Token 不再出现在日志、状态卡与截图中
- 新增 `/api/alerts` 告警游标接口，客户端可按 `since` 增量拉取监控状态变化
- 概览图表固定返回 12 个小时桶（含空桶），不再为一小时画一根超宽柱子

## v2.3.0

- 新增实验性功能开关：管理员可在后台控制是否展示实验功能入口，关闭时相关 API 返回 `404`
- 新增 IP 优选实验室：支持自定义 Host、TLS SNI、探测路径、接受状态码、IP 段、并发、超时与保留 Top N
- 支持实时进度、执行历史、按输入段聚合命中统计，并可一键复制或剔除 `0 命中` IP 段
- 支持定时执行与华为云 DNS A 记录自动更新，Secret Key 使用应用加密密钥 AES-GCM 加密存储
- 新增实验功能中英文文档、API 说明与关于页介绍

## v2.2.3

- 大幅降低首屏体积：MiSans 改为核心子集 + unicode-range 分片按需加载，核心子集已包含界面全部文字，首屏字体从约 19 MB 降到 373 KB，用户内容里的生僻字才按需补拉分片
- 后端启用 gzip 压缩静态资源：主 JS 由 450 KB 降到 149 KB，字体样式表由 116 KB 降到 9 KB
- 字体文件返回长效缓存头，重复访问不再逐个重新校验；请求不存在的字体不再回落到前端首页
- 响应式断点统一为 480 / 640 / 768 / 1024 四档（此前有 11 种），缩放窗口时各页面不再各自错位重排
- 统一各页面标题区间距，移除 9 个页面对共享样式的重复覆盖
- 修复控制面板快捷操作在 640–768 px 宽度下列数与预期不符的问题

## v2.2.2

- 修复域名绑定一直使用全局配置的问题：无论选择哪个隧道 / 转发端口，ingress 与 CNAME 都会落到全局配置的隧道与端口；改为优先使用当前用户自己保存的隧道与转发地址，未配置时回退全局配置

## v2.2.1

- 修复注册 / 找回密码人机验证一直不通过：Turnstile 组件 action 与接口校验的 action 不匹配（发送邮箱验证码、找回密码、重置密码），改为仅登录页携带 action
- 安全修复：普通用户未绑定自己的 Cloudflare OAuth 时不再回退使用管理员的静态凭据，未授权用户无法查看或操作管理员的隧道、域名、DNS 与监控

## v2.2.0

- 状态页支持绑定独立自定义域名，并按请求 Host 跳转到对应公开页面（状态页 Host 隔离）
- 状态页直连 / 优选双接入：优选模式区分访问域名与辅助回源域名，Custom Hostname 的 Custom Origin 改为辅助回源域名，并同步配置双域名 ingress
- 保存自定义域名时自动创建 Cloudflare 橙云 CNAME，并复制面板隧道 ingress 的服务与源站参数；自动配置失败时保留状态页设置并返回警告，界面继续提供手动 DNS 与 ingress 指引
- 支持为每个监控选择或手填优选 CNAME，留空时使用全局默认值
- 修复监控项目所有者未持久化导致的跨用户访问问题，并回填历史空归属项目
- 恢复每用户 Telegram 长轮询 / Webhook 双模式：Webhook 密钥自动生成且仅存后端，每用户独立路由验签与账户隔离

## v2.1.0

- 用户主页：自定义展示名称与头像（支持图片上传），未绑定邮箱时可直接绑定，已绑定可修改邮箱
- 可选人机验证：Cloudflare Turnstile，后台可配置开启/关闭与 Site Key / Secret，覆盖登录、注册与找回密码
- 用户通知中心：每个用户独立配置通知渠道（邮箱 / 自有 Telegram Bot / 两者）与事件开关，支持多收件人邮箱与登录通知
- Telegram 远程控制开放给所有用户：每人一个独立 Bot（长轮询），隔离操作各自的隧道 / DNS / 域名，管理员旧全局 Bot 自动迁移为个人 Bot
- 通知与远程控制 Bot Token 独立存储，支持「一键复用」：只配了一侧时可一键复制到另一侧（两侧都已配置则各走各的）
- Telegram API 端点改为面板级可配置（自定义反代），远程控制与通知发送统一走该端点，解决国内无法直连官方 API 的问题
