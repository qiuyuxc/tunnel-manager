# Translation resources

Web and Android share `zh-CN.json` and `en.json`. Message IDs stay stable when
wording changes. Parameters use `{name}` placeholders and stay outside translations.
User names, resource values, API identifiers and Telegram commands are not translated.

The Web client loads these files locally. Android string resources are generated by
`node tools/i18n/generate.mjs`; commit the generated resources with catalog changes.
Run `node --test tools/i18n/*.test.mjs` to check keys, placeholders, numeric limits,
addresses and command names.

Documentation uses a common page manifest and translation messages. Add or reorder a
page once in `docs/.vitepress/navigation.json`; edit both Markdown sections in
`docs/content/<page>.json`. The documentation build checks both languages and generates
the Markdown routes; generated pages must not be edited directly.
