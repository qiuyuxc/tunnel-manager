## 预览

在 `frontend` 目录执行 `npm run preview:assistant`，访问 `http://127.0.0.1:8083`。

- `?variant=A`：协作工作台，对话在左，任务和资源上下文在右。
- `?variant=B`：任务指挥台，以待确认、执行中、已完成三列组织任务，对话改为底部指令入口。
- `?variant=C`：分步配置，按描述目标、核对变更、查看结果展开。
- `device=desktop` / `mobile` / `app`：桌面、网页移动端、Android APP 布局模拟。
- `theme=dark` / `light`：沿用现有项目两套配色。
- `state=ready` / `empty` / `running` / `failed`：默认、空会话、执行中、失败示例。

底部左右按钮或键盘方向键切换方案，输入框内不会拦截方向键。顶部可切换三端、状态和主题。所有资源名称、任务日志、耗时与结果均为示例。

## 视觉与交互

- 参考意图：以 Linear 为紧凑任务层级参考，以 Raycast 为快捷输入参考，以 Slack 为上下文导航参考。实际视觉服从本项目，而非复制其他产品。
- 配色沿用 `android/palette-tokens.json` 与现有 Web 设计稿：深色底 `#0B1211`、面板 `#151D1C`、薄荷绿 `#6EDDAD`；浅色底 `#EDF4F0`、面板 `#FAFDFB`、强调色 `#127250`。
- 使用已有 MiSans 字体子集与系统中文回退。标题不做营销式巨幅排版，长域名完整换行，数字等宽对齐。
- 单一 CSS 策略：独立原生 CSS，以语义变量和容器查询适配。按钮圆角 12px，面板 20px，标签胶囊形。无渐变和背景模糊。
- 按下缩放、任务状态淡入、抽屉进入均为短时动效；支持系统减少动态效果偏好。
- 桌面采用应用侧边栏；移动端收起侧边栏、任务变为底部抽屉；APP 增加模拟系统状态栏、底部导航与手势区域。APP 模式是浏览器内设计稿，不是已集成的原生页面。
- 移动端与 APP 保留底部中间的加号，不设独立助手标签。点击加号展开快捷操作，保留「新建隧道」「绑定域名」，新增「AI 助手」入口；进入助手时保留当前会话、草稿与任务。
- 写操作先展示变更清单，明确资源与修改前后内容，勾选确认后才模拟执行。并发任务可暂停、继续、重试，不会实际修改 DNS、隧道或监控。

## AI 连接配置

- 助手页右上角的设置图标打开「AI 连接配置」，桌面与两种移动布局均可访问；桌面的助手策略菜单也提供入口。
- 默认关闭全站共享，各用户自行填写 API 端点与密钥，个人配置分别保存；管理员也有独立个人配置。
- 只有管理员能开启全站共享并编辑专用共享配置。开启时必须填写有效端点和密钥，点击保存才生效，取消不修改当前模式。
- 开启共享后所有用户统一采用管理员共享配置，普通用户只看到配置状态，没有共享端点或密钥输入框，也没有开关。共享只影响 AI 接口，不代表共享会话、任务或资源权限。
- 关闭共享后恢复各自的个人配置；个人未配置则需自行填写，不自动回退到管理员配置。共享配置不可用时也不回退到用户个人密钥。
- 已设置的密钥不回显，留空表示保留，填写新值表示替换。
- 配置弹窗有单独标明的审核视角选择器，可切换「管理员」「用户 A」「用户 B」检查配置隔离。此选择器仅用于设计审核，不是真实身份认证。
- 本稿所有配置只保存在浏览器内存，API 密钥只模拟保存状态，保存后丢弃其内容。请勿填写真实密钥；不使用本地持久化，不连接任何模型服务。正式实现仍需服务端鉴权、加密存储和后端代理调用。
